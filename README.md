# Alex Johnson - Portfolio Website

Modern, responsive portfolio showcasing full-stack and blockchain development skills.

## 🚀 Features

- **Modern Design**: Glassmorphism effects and gradient animations
- **Responsive**: Mobile-first design across all devices  
- **Smooth Animations**: Framer Motion for enhanced UX
- **SEO Optimized**: Meta tags and structured data
- **Performance**: Optimized assets and lazy loading

## 🛠️ Tech Stack

- React.js (Hooks + Functional Components)
- Tailwind CSS
- Framer Motion
- React Icons

## 📁 Improved Structure

```
src/
├── components/
│   ├── ui/              # Reusable UI components
│   └── sections/        # Page sections
├── hooks/               # Custom React hooks
├── utils/               # Utility functions
├── styles/              # Global styles
├── constants/           # App constants
└── data/               # Portfolio data
```

## 🚀 Quick Start

```bash
npm install
npm start
```

## 🎨 Key Improvements

- **Better Organization**: Separated UI components from sections
- **Custom Hooks**: Reusable logic for scroll animations
- **Animation Utils**: Consistent motion variants
- **Constants**: Centralized configuration
- **Optimized CSS**: Tailwind layers for better performance
- **Cleaner Imports**: Index files for better DX

## 🌐 Deployment

### Vercel
```bash
npm i -g vercel && vercel
```

### Netlify
```bash
npm run build
# Upload build/ folder to Netlify
```

## 🔧 Customization

Edit `src/data/portfolioData.js` for:
- Personal information
- Skills and projects
- Work experience
- Social links

Modify `tailwind.config.js` for styling changes.
